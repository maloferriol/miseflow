# Does MiseFlow ship as a desktop app or run in the browser?

Type: grilling
Status: open
Blocked by: —

## Question

Research on the backend ticket found that watching and writing a folder of `.cook` files depends on the app platform: a desktop shell (Tauri, Electron) can do it; a browser-only app or PWA can't do it reliably. "Local-first" doesn't settle which. Decide only as far as this map needs: will MiseFlow have a desktop shell with file system access, and does Supabase stay on the table, given that it would make the server canonical?
